# 🎮 Игра "Угадай число" на Go

Простая консольная игра, где нужно угадать число от 1 до 100.


# 🛠 Технические характеристики
✨Используется стандартная библиотека Go:

✨math/rand для генерации случайного числа

✨fmt для ввода/вывода

✨time для инициализации генератора случайных чисел



# 🚀 Запуск:
1. Убедись, что у тебя установлен [Go](https://golang.org/).
2. Открой терминал в папке проекта и выполни:
   ```bash
   go run main.go

# 🎯 Правила:
У тебя 10 попыток.

Программа подсказывает, больше или меньше загаданное число.

Если угадаешь — победа!

# 🔴 Главное:
Игра пока не завершена, поэтому будут обновления. Это бета-версия, предназначенная для проверки навыков.
