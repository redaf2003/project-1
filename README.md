# Игра "Угадай число"

Простая консольная игра, где нужно угадать загаданное число за определенное количество попыток.

## Особенности
- 🎮 Три уровня сложности
- 🔥 Подсказки "Горячо/Холодно"
- 📊 Сохранение результатов в файл
- 🌈 Цветной интерфейс

## Как установить
1. Убедитесь, что у вас установлен Go (версии 1.16+)
2. Установите зависимости:
   ```bash
   go get github.com/fatih/color
   Соберите и запустите:
   go run main.go

## Как играть ?
1. Выберите уровень сложности:
1)Лёгкий: числа 1-50, 15 попыток
2)Средний: числа 1-100, 10 попыток
3)Сложный: числа 1-200, 5 попыток

2. Вводите числа и получайте подсказки:
* 🔥 Очень горячо! — очень близко (разница ≤3)
* 🔥 Горячо! — близко (разница ≤7)
* 😊 Тепло — средне (разница ≤15)
* 🥶 Холодно — далеко (разница >15)

3. После игры можно сыграть заново.

## Сиситема сохранения результатов
Игра сохраняет историю в файл results.json с информацией:

Результаты игры:
* Дата и время проведения
* Итог (победа или поражение)
* Количество попыток
* Загаданное число
* Уровень сложности

Пример записи:
{
    "date": "2025-07-24 20:42:10",
    "outcome": "win",
    "attempts": 0,
    "target": 37,
    "difficulty": "Лёгкий"
  },

## Цвитная тема:
🟢 Зелёный - победа, успешные сообщения
🔴 Красный - ошибки, проигрыш
🟡 Жёлтый - попытки, ввод данных
🔵 Голубой - информационные сообщения

## Структура кода:
* main.go - главный файл с игровой логикой
* GameResult - структура для сохранения результатов
* Difficulty - параметры уровней сложности
